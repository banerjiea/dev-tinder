# 💘 DevTinder Frontend

Frontend for the developer matchmaking platform — built with React, Redux Toolkit, and DaisyUI.
Handles user interaction, matching flow, and real-time chat interface.

## 🚀 Features

- ⚛️ Modern React UI

- 🧠 Global state management with Redux Toolkit 

- 💬 Real-time chat interface

- 🔐 Authentication flow (login / register)

- 🤝 Match & connection management

## 🛠 Tech Stack

- React

- Redux Toolkit

- React Router

- Tailwind CSS

- DaisyUI

- Socket client (for real-time chat)

- Axios / Fetch API
